# Dot Bible 표지 제작 스펙

Dot Library 카드에 들어갈 표지. 기존 표지 4종(오만과 편견·모비딕·월든·종의 기원)을
캡처에서 **픽셀 단위로 실측**해 정리했습니다. 눈대중이 아니라 측정값입니다.

---

## 1. 규격

| 항목 | 실측 | 제작 권장 |
|---|---|---|
| 카드 표시 크기 | 190 × 260 px | — |
| 비율 | **1 : 1.368** | 그대로 유지 |
| 카드 피치 | 246 px (거터 56 px) | — |
| 제작 해상도 | — | **1200 × 1642 px** (@2x 여유) |
| 파일 | — | PNG, sRGB |

1:1.368은 흔한 2:3(1.5)이나 A판(1.414)이 아닙니다. **기존 4종이 모두 이 비율**이라
맞춰야 그리드에서 튀지 않습니다. 1200 × 1642로 만들면 정확히 떨어집니다.

썸네일이 190px 폭이라는 걸 전제로 그리세요. 이 크기에서 읽히지 않는 디테일은
넣어도 보이지 않습니다.

## 2. 주변 UI 색 (표지가 놓이는 환경)

| 위치 | 값 |
|---|---|
| 페이지 배경 | `#FBF8F3` |
| 카드 하단 영역 | `#F1EDE9` |
| 히어로 배너 | `#EAEEF3` |
| 카테고리 pill | `#C28975` 계열 |
| 제목 텍스트 | `#292724` |
| 저자 텍스트 | `#6F695F` |

표지 가장자리에 **테두리나 그림자가 없습니다.** 이미지가 그대로 카드가 됩니다.
따라서 표지 자체의 네 변이 배경(`#FBF8F3`)과 구분돼야 합니다 — 밝은 크림으로
가장자리를 마감하면 카드 경계가 사라집니다.

## 3. 기존 4종 팔레트 (지배색 상위, 실측)

**오만과 편견** — 밝은 수채, 목가적
```
#E0D3BE 19.5%   #ABAE89 18.7%   #77755B 18.4%   #ECE1D0 16.2%   #F9ECDA 13.6%
```
전체 명도 L41~91. 어두운 색이 없습니다. 크림·세이지·올리브.

**모비딕** — 어두운 극적, 유일한 저명도
```
#06080A 26.9%   #2A3840 20.0%   #43545D 17.3%   #1B2125 14.9%   #0D1A23 10.5%
```
L3~31. 색조 H200~210으로 청록 단일 계열. 4종 중 유일하게 어둡습니다.

**월든** — 가을 수채, 크림 여백이 넓음
```
#594F34 21.4%   #FDF8F0 19.2%   #FAF7F0 18.2%   #91835D 16.5%   #B7AD87 12.9%
```
H36~47 황토 단일 계열 + 크림 37%. 종이 여백이 가장 많습니다.

**종의 기원** — 세피아 판화
```
#2E2213 21.2%   #857151 19.9%   #5E4B32 17.1%   #453925 16.1%   #F0E3BF 13.6%
```
H33~44 갈색 단일 계열. L12~84로 명암 폭이 큽니다.

### 여기서 읽히는 규칙

**색조가 하나로 묶입니다.** 4종 모두 지배색 5개의 H값이 좁은 범위에 모여
있습니다(모비딕 H200~210, 월든 H36~47, 종의기원 H33~44). 보색 대비를 쓰지
않습니다. **단색조 + 명도 변주**가 이 라이브러리의 문법입니다.

**채도가 낮습니다.** S값이 대부분 13~45. 60을 넘는 건 크림 하이라이트뿐입니다.

**밝은 것 3 : 어두운 것 1.** 모비딕만 어둡고 나머지는 밝습니다. 그리드에서
어두운 표지가 시선을 잡는 구조라, 새 표지를 또 어둡게 하면 균형이 깨집니다.

## 4. Dot Bible 제안

### 콘셉트

**시편 119:105** — "주의 말씀은 내 발에 등이요 내 길에 빛이니이다."
앱의 내장 암송 구절에 실제로 들어 있는 절입니다.

황혼 무렵 낮은 언덕 사이로 난 좁은 길. **그 길이 가지런한 줄로 늘어선 볼록한
점들로 포장돼 있습니다** — 점자 셀처럼. 길 끝에 놓인 작은 토기 등잔에서 따뜻한
빛이 점들을 타고 앞으로 흘러옵니다. 올리브나무 실루엣 몇 그루.

성경 본문과 닷패드가 한 화면에서 만나는 그림입니다. 기기를 그리지 않고도
제품이 무엇인지 말합니다.

### 팔레트

기존 규칙(단색조 + 낮은 채도)을 따라 **따뜻한 황토 계열 + 앰버 발광** 하나로
묶었습니다. 월든과 이웃해도 겹치지 않게 명도 분포를 다르게 잡았습니다.

| 역할 | 값 | 비중 |
|---|---|---|
| 종이 바탕 | `#F7F1E6` | 30% |
| 하늘(황혼) | `#C9B99E` → `#8E8168` 그라데이션 | 25% |
| 언덕·나무 그림자 | `#4A4030` | 20% |
| 점자 길(솟은 점) | `#E8D9BC` | 12% |
| 등잔 발광 | `#E8A24A` | 10% |
| 최암부 | `#2B2419` | 3% |

앱의 브랜드 오렌지 `#FF4F00`은 **쓰지 마세요.** 채도가 너무 높아 이 그리드에서
혼자 튑니다. 등잔 빛은 `#E8A24A`로 눌러야 월든·종의기원과 같은 톤에 앉습니다.

### 구성

```
┌─────────────────────┐
│                     │  상단 33% — 하늘. 제목 자리로 비움
│                     │
├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤  ← 제목 베이스라인
│      ·  ·  ·        │
│    ·  ·  ·  ·       │  중단 40% — 점자 길이 원경에서
│   ·  ·  ·  ·  ·     │  전경으로 넓어지며 내려옴
│  ·  ·  ·  ·  ·  ·   │  끝에 등잔(화면 상단 1/3 지점)
│ ·  ·  ·  ·  ·  ·  · │
├─────────────────────┤
│                     │  하단 27% — 전경 언덕, 어둡게
└─────────────────────┘
```

점은 **원근에 따라 크기가 변하되 줄 간격은 일정하게**. 점자는 격자가 규칙적일 때
점자로 읽히므로, 흐트러뜨리면 그냥 자갈길이 됩니다.

### 타이포

기존 4종은 제목이 표지 안에 그려져 있습니다. 같은 방식으로 갑니다.

| 항목 | 값 |
|---|---|
| 제목 | **Dot Bible** |
| 위치 | 상단, 표지 높이의 18~24% 지점 |
| 서체 | 세리프 — 기존 4종이 모두 명조 계열. Noto Serif KR 또는 Source Serif |
| 크기 | 표지 폭의 14~16% (1200px 기준 168~192px) |
| 색 | `#3A3020` (밝은 하늘 위) |
| 자간 | 살짝 넓게, +2% 내외 |
| 부제 | 없음. 카드 아래 「닷패드로 읽는 다국어 성경」이 이미 붙습니다 |

**한글 제목은 넣지 않습니다.** 제품명이 한국어·영어 모두 Dot Bible로 통일됐고,
표지에 두 언어를 얹으면 190px에서 읽히지 않습니다.

월든·종의기원 표지에 있는 원형 씰은 **넣지 마세요.** 그건 그 두 권의 장식이지
라이브러리 공통 요소가 아닙니다.

### 질감

과슈·수채의 붓 자국, 종이 결이 은은하게. 벡터처럼 매끈하면 4종 사이에서
혼자 이질적입니다. 노이즈는 190px 축소 시 뭉개지므로 과하지 않게.

## 6. 확인용 체크

- [ ] 190px 폭으로 축소해도 등잔 빛과 길이 구분되는가
- [ ] 월든(`#594F34` 황토) 옆에 놓았을 때 구분되는가
- [ ] 가장자리가 `#FBF8F3` 배경에 묻히지 않는가
- [ ] 제목이 하늘 영역 안에서 대비 4.5:1 이상인가
- [ ] 점의 격자가 규칙적으로 읽히는가
