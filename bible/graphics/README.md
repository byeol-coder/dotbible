# 핵심 촉각 그래픽

본문에 딸린 지도·도표를 촉각으로 보여주는 선택 기능입니다.
파일이 있으면 리더 화면에 "핵심 그래픽 보기" 버튼이 나타납니다.

스키마: `<책번호>-<장>.json`

```json
{ "hex": "...600자 DTMS hex...", "alt": "설명", "verse": 9 }
```

- `hex` — 60×40 핀 격자 전체(300바이트 / 600 hex). DTMS 코퍼스에서 authoring
- `alt` — 그래픽을 표시할 때 음성으로 안내할 설명 (필수)
- `verse` — 관련 절 번호 (선택)

없으면 버튼이 숨겨질 뿐 앱 동작에는 영향이 없습니다.
